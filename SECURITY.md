# Security policy／資安回報

- **Please do not open a public issue for security problems.** Use GitHub's private vulnerability reporting
  (Security tab → "Report a vulnerability").
  資安問題請不要開公開 issue，請用 GitHub 的私下回報（Security 分頁 →「Report a vulnerability」）。
- This project is provided as-is, without support or response-time guarantees; fixes are best-effort.
  本專案照現狀提供，不提供支援、不保證回覆時間。
- Releases are published to npm only through GitHub Actions with provenance (Trusted Publishing);
  no npm token exists for this package. 發布只經 GitHub Actions（附 provenance），本套件沒有 npm 鑰匙。
